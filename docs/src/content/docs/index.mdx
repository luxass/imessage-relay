## How the relay works

The relay runs on macOS 14 or newer. Reads use your local Messages database.
Sends use Messages.app. The relay does not use private frameworks or process injection.

The HTTP server listens on `http://127.0.0.1:8080` by default. Every request requires your bearer token.
The relay process needs Full Disk Access to read Messages.
Read the [configuration guide](/configuration/) before changing its listening address or allowed recipients.
